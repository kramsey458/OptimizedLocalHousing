Install guide

About five minutes. You need Timberborn 1.1 and nothing else: no other mods are required.

Back up first. As with any mod, keep a copy of your save so you can undo the moves the mod makes.

Requirements

  • Timberborn 1.1. The mod is built against 1.1.2.4 and asks for 1.1.0.0 or newer. A future game update could break it.
  • Windows. That is the only system it has been checked on. It is an ordinary game mod, so other systems may work, but the Mods folder is in a different place there.
  • No other mods. No Harmony, no Mod Settings.
  • Do not run it alongside Bobingabout's Housing Optimize or Commute Balancer. It disables itself if it sees either of them enabled. See the FAQ.

Step by step

  1. Back up your save

    Copy the save you want to use from Documents\Timberborn\Saves so you can go back if you don't like the result.

  2. Download the mod

    Download 1.1.1

    Get OptimizedLocalHousing-v1.1.1.zip from the release page. It is listed under Assets; don't download "Source code". The mod is distributed from GitHub, not the Steam Workshop.

  3. Close Timberborn

    Make sure the game is fully closed before you copy files into its Mods folder.

  4. Extract into your Mods folder

    Extract the ZIP into Documents\Timberborn\Mods. It contains one folder, OptimizedLocalHousing, and you should end up with the layout shown below. If you extracted into a new folder, you may have a doubled OptimizedLocalHousing\OptimizedLocalHousing: move the inner one up (the layout shows both).

  5. Enable it and restart

    Start Timberborn, open Mods from the main menu, tick Optimized Local Housing, and restart the game when it asks. Don't run them together: Optimized Local Housing turns itself off if Housing Optimize or Commute Balancer is enabled. Menu wording can differ a little between game versions.

  6. Load your save and let the game run

    On a save the mod hasn't seen before, the first pass starts as soon as the game is ticking (not while paused). After that it runs at the start of every in-game day. Check that it ran.

Folder layout

This is what a correct install looks like. The game reads the manifest and the DLL from the version-1.1 folder.

With a doubled folder the game doesn't find the mod. Move the inner OptimizedLocalHousing folder up one level and delete the empty one.

Check that it works

The mod has no menu and no settings. It writes one line to the game log at startup and one line after every pass.

  1. Quit the game, then open %USERPROFILE%\AppData\LocalLow\Mechanistry\Timberborn\Player.log. If you have already restarted, the previous session is in Player-prev.log.
  2. Search for [OptimizedLocalHousing]. You should see this at startup: 
    [OptimizedLocalHousing] 1.1.1 loaded.
  3. After a pass finishes you should see a summary line (roughly 90 seconds to two minutes at normal game speed on a colony of a few hundred beavers, faster at higher speeds). This is a real line from a live game, and your numbers will differ:
    [OptimizedLocalHousing] Pass 26: 356 adults, 104 homes, 167 workplaces; 5354 route queries over 182 ticks; 2 move cycles applied (0 rejected, 0 stale), 0 disconnected commutes repaired, route cost saved 177.
    356 adults, 104 homes, 167 workplaces
    who was in the plan
    5354 route queries over 182 ticks
    the work, spread out
    2 move cycles applied
    groups of beavers who swapped beds
    0 rejected, 0 stale
    moves thrown out at the fresh check, or because something changed during the pass
    0 disconnected commutes repaired
    beavers moved to a home that can reach their work
    route cost saved 177
    how much shorter the colony's walk got

No line, or an error line? Head to Troubleshooting.

Multiplayer

Every player must install the same version of the mod and run the same game version, because the mod changes which beaver lives where and all players' games have to agree. The pass is designed to give the same result on every machine and to resume correctly after a save, a reload or a join. It has been used in a live hosted co-op session (about 11,000 ticks and 15 passes) with no desync reported by the host. That session ran the code the stable release started from; this release hasn't been played live by two players yet, so if you try it please tell us how it went.

Updating

  1. Close the game and delete the old Mods\OptimizedLocalHousing folder.
  2. Extract the new ZIP into Mods as above.
  3. Start the game. Your saves keep working.
  4. In multiplayer, every player must update to the same version together.

Uninstalling

Untick it in the Mods menu and restart, or delete the OptimizedLocalHousing folder. Nothing else is needed. Beavers keep the homes they have, and any leftover mod data in your save is ignored. To undo the moves already made, go back to a save from before you installed it.

Verify the download (optional)

In PowerShell, from the folder you downloaded to:

Get-FileHash .\OptimizedLocalHousing-v1.1.1.zip -Algorithm SHA256

The hash should be:

cc6b905d0021c3119f15a85186d6a7197e7955bed890d0134d0c6a2f2f654059

The same hash is in the SHA256SUMS file attached to the release.
